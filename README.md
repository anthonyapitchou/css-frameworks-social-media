# CSS Frameworks Social Media

A responsive social media application built with HTML and Tailwind CSS as part of the Noroff CSS Frameworks assignment.

## Features

### Authentication Page

* Login/Register form
* HTML validation
* Password minimum length of 8 characters

### Profile Page

* Profile image
* Username and user information
* Follow button
* Followers and following statistics
* Recent posts section

### Feed Page

* Search bar
* Sort options
* Create post form
* Post cards with thumbnails

## Technologies Used

* HTML5
* Tailwind CSS 4
* npm
* Git & GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/anthonyapitchou/css-frameworks-social-media.git
```

Install dependencies:

```bash
npm install
```

Run development mode:

```bash
npm run dev
```

Build production CSS:

```bash
npm run build
```
